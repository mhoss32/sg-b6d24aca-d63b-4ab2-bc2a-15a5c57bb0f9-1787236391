## Vision
Nexus — A product intelligence platform that lets users explore use cases, user stories, and functionality of a new software product through an interactive network graph of glowing bubbles.

## Design
- Background: #0A0A0F (near-black with blue tint)
- Primary: #00D4FF (electric cyan) for Use Cases
- Secondary: #FF6B6B (coral) for User Stories
- Accent: #A78BFA (purple) for Functionality
- Text: #E2E8F0 (slate-200)
- Muted: #334155 (slate-700)
- Lines: rgba(0, 212, 255, 0.15) with glow
- Fonts: IBM Plex Sans (headings/body), IBM Plex Mono (data labels)
- Style: Dark technical network graph, force-directed feel, glowing nodes with connection lines

## Features
- Interactive canvas network graph with draggable/clickable bubbles
- Three node types: Use Cases (cyan), User Stories (coral), Functionality (purple)
- Connection lines showing relationships between nodes
- Detail panel on node click
- Smooth animations and hover glow effects
- Zoom and pan capability
- Legend and navigation controls
